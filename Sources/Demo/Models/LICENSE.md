# Demo models

`OrientationTest.glb` is an unmodified copy of the OrientationTest model (glTF-Binary) from the
Khronos glTF Sample Assets repository, https://github.com/KhronosGroup/glTF-Sample-Assets
(Models/OrientationTest/).

© 2017, Analytical Graphics, Inc.; mesh and textures by Ed Mackey; Khronos.
Licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode).

`BoomBox.glb` is the BoomBox model (glTF-Binary) from the same repository (Models/BoomBox/),
with its four 2048x2048 textures downscaled to 512x512 (the base color re-encoded as JPEG) to
keep it small; geometry and materials are unchanged.

© 2017, Microsoft. Licensed under [Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode)
(CC0-1.0, per the model's LICENSE.md and README.md in the repository).

`Fox.glb` is an unmodified copy of the Fox model (glTF-Binary) from the same repository
(Models/Fox/): a skinned low-poly fox with three animations (Survey, Walk, Run).

- Model by PixelMannen, © 2014, public: [Creative Commons Zero v1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode)
  (https://opengameart.org/content/fox-and-shiba).
- Rigging and animation by tomkranis, © 2014: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode)
  (https://sketchfab.com/3d-models/low-poly-fox-by-pixelmannen-animated-371dea88d7e04a76af5763f2a36866bc).
- Conversion to glTF by @AsoboStudio and @scurest, © 2017: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode)
  (https://github.com/KhronosGroup/glTF-Sample-Models/pull/150#issuecomment-406300118).
